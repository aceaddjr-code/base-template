## 导航与菜单

- 侧边栏按当前账号的菜单权限显示入口；首页的「模块入口」与侧边栏一致。
- 顶栏放大镜或快捷键 **Ctrl / Cmd + K** 打开菜单搜索：支持中文名称、路径与别名，方向键选择、Enter 进入、Esc 关闭。
- 浏览器刷新或退出登录后，回到登录页重新进入。

## 列表、筛选与视图

- 筛选输入是草稿：编辑条件后点「查询」或按 Enter 才会应用；已应用条件以标签展示，可逐个移除。
- 「更多条件」收纳低频条件；日期快捷项（今天 / 近 7 天 / 本月）按当天日历计算。
- 「视图」按钮可把常用条件 + 排序保存为个人常用视图（保存在当前浏览器的当前账号下），设为默认后进入页面自动应用。
- 翻页或修改条件会清空已勾选的行；导出使用与列表一致的已应用条件。

## 详情与编辑

- 普通查看与编辑共用详情抽屉：点「编辑」原地切换字段，保存或取消后回到查看态。
- 有未保存的修改时，取消 / Esc / 关闭会弹出「继续编辑 / 放弃修改」确认；刷新页面时浏览器也会再次确认。
- 必填、长度等校验错误显示在字段旁边，顶部摘要可点击定位到第一个错误。
- 若保存时提示「记录已被他人修改」，说明他人在你打开之后更新过这条记录：你的输入仍保留，可选择继续编辑或载入最新内容。

## 个人偏好

- 列显隐、排序与列宽按账号分别保存在当前浏览器；换设备或换账号各自独立。
- 最近访问、菜单搜索历史、常用筛选视图同样按账号隔离。
