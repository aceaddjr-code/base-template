# 任务分流标签

| 标准角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待评估需求与可执行性 |
| needs-info | needs-info | 等待补充信息或必要确认 |
| ready-for-agent | ready-for-agent | 已明确且可由 Agent 实施 |
| ready-for-human | ready-for-human | 需要由人实施 |
| wontfix | wontfix | 明确不实施 |

技能要求设置某个分流角色时，使用本表对应标签。执行中的领取和完成状态遵循任务跟踪器约定。
