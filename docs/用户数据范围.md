# 用户数据范围

入口：系统管理 → 用户管理 → 数据范围。管理员按用户分别设置每个业务表单，未配置的表单默认仅本人。当前模板只有示例事项注册了业务数据范围。

每张表单共用一组数据范围：自己的、全部、按用户、按部门。按用户和按部门必须指定目标，部门包含下级部门；列表可见集合始终包含本人。全部和指定目标不会自动打开操作开关。

范围内分别勾选六项：查看他人详情、查看本人详情、编辑他人、编辑本人、删除他人、删除本人。本人与他人按记录归属人区分，不按创建人或最后修改人区分。

共同范围决定列表中有哪些记录；查看详情开关控制详情、履历、附件读取和导出。编辑同时要求相应的查看详情开关，删除只使用对应删除开关。操作权限码仍必须满足，六个开关不能替代角色权限或突破共同范围。单据附件修改跟随单据编辑资格。

例如：范围选部门 A，勾选查看他人、查看本人、编辑本人，关闭编辑他人和两个删除开关。该用户可看到本人及部门 A（含下级）的记录，可查看详情，只能编辑本人记录，不能删除任何记录。

旧配置新增的三个本人开关默认开启。只配置过「所有表单」而未配置具体表单的用户，升级后该表单收紧为仅本人，需逐表单重新配置。未配置用户默认仅本人。系统管理员保留管理例外。保存后目标用户旧会话失效，需要重新登录。

加载失败时不能保存；切换用户/部门范围时清空目标，避免数字 ID 被混用。每个表单直接配置，未填写目标由前后端共同拒绝。保存按当前表单清单全量替换：遗留「所有表单」（__global__）行不再补写也不接受提交，已下线表单的存量配置行在面板中忽略并提示，两者都随保存清除；开关缺省值由后端归一化后下发，前端不自行复刻。
