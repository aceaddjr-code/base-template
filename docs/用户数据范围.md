# 用户数据范围

入口为「系统管理 → 用户管理 → 可见范围」。示例事项和附件管理各配置一项范围：仅本人、全部、按用户或按部门。按用户和按部门包含本人，部门包含下级部门。未配置时仅本人。

角色决定可以做哪些操作。普通编辑、删除只允许操作本人记录。对范围内的他人记录，还需同时拥有基础动作和「编辑他人记录」或「删除他人记录」权限。本人与他人以记录归属人区分。业务附件按所属单据判断，独立文件按文件归属判断，未挂接附件仅上传者或系统管理员可管理。

例如，可见范围选部门 A。浏览者只能查看。角色加上普通编辑后，可查看部门 A 和下级部门的记录，只能编辑自己的记录。再授予「编辑他人记录」后，才能编辑可见范围内同事的记录。删除有独立授权。

回收站恢复和彻底删除拥有独立的角色权限。本人操作需要基础权限，他人操作需要基础和对应的他人权限。业务状态和文件完整性继续由后端检查。系统管理员保留管理例外。

**团队成员（记录参与者）口径**（2026-11-13 起，见 [ADR-0004](adr/0004-单据团队成员可见采用参与者直通口径.md)）：示例事项单据上有「团队成员」多选用户字段（至多 50 人），成员身份在上述共同范围之外**额外**提供该单据的可见性——列表、详情、履历、附件与导出均可见，回收站同样按此口径。能执行什么操作仍由成员自身的角色权限码决定：有 `example-items:update` 码即可编辑该单据、有 `delete` 码即可删除，**无需**「编辑他人/删除他人」权限、不受本人/他人开关约束。因此给角色授予删除权限即意味着成员可删除其参与的单据，角色设计按最小权限分配。成员变更记录在单据修改日志中，新加入成员会收到站内通知。

升级后，存量用户的旧操作限制会继续生效。角色仍需满足新权限要求。配置页会提示旧限制，管理员核对角色后保存可见范围，即切换到新规则。复制配置只复制范围和目标，保存后目标用户需重新登录。
