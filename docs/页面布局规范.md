# 页面与交互规范

本文件定义页面布局和交互约定。颜色、间距和组件主题分别以 `frontend/src/style.css`、`frontend/src/App.vue` 为准；组件接口和行为以源码为准。

视觉依据为 `docs/design/DESIGN.md`（用户提供的 OpenCode 设计规范原文），在企业管理系统中的适配说明见 `docs/design/README.md`。

## 列表页

- 使用 `Page`、`PageToolbar`、`ListFooter` 和 `useResizableColumns`。完整接入参考 `frontend/src/views/examples/items/index.vue`。
- 页面占满内容区；标题和页脚固定，内容区内部纵向滚动。flex 滚动链上的 `min-height: 0` 必须保留。带 `#footer` 插槽的页面由 `Page` 自动去掉底部内边距（`.starter-page.has-footer`），让页脚贴住内容区底部，表格多出 24px 可用高度。
- 表格设置 `row-key`、`:pagination="false"` 和横向 `scroll.x`。分页在右下角，使用后端 total；搜索和改变每页条数时回到第一页。表头为浅底加 1px 深色分隔线，行高 40px（`--row-h`，由 `td` 上下 padding 决定，`height` 只是下限）；选中行为中性底色加左侧 2px 墨条；空态使用 `[ 暂无文案 ]`，不使用插画。
- 表头固定在列表内滚动：用 `scroll.y` + `useTableScrollY(containerRef)` 实测可用高度（容器高 - 工具栏 - 表头），不要写死 `calc(100vh - N)`。设置 `scroll.y` 后 antd 会把表头单独渲染，页面本身不再滚动，`StickyScrollBar` 会取 `.ant-table-body` 作为横滚源。
- 按行设置 `td` 内边距时必须限定到 `tr.ant-table-row`：`<tr class="ant-table-measure-row">` 是 antd 用来同步列宽的隐藏行，行内样式是 `height:0;padding:0`，一旦被继承到通用 `tr > td` 规则上就会被撑成表头与表体之间的一条空白带。
- 表格不显示系统滚动条（`::-webkit-scrollbar` 宽度为 0），只用滚轮或触摸滑动。滚动条宽度归零后 antd 不再生成表头右端的 `ant-table-cell-scrollbar` 占位列，固定列 `right` 回到 0，操作列可以直接贴住表格右边界。
- 表格外框：左外侧（首列 `border-left`）、表头上沿（`th` 的 `border-top`）、右侧（最后一列 `border-right`）各一条 1px 边线，底部由页脚的一条 `border-top` 收口，四边闭合。
- 工具栏搜索框外壳与「搜索」按钮同为 `--control-h`；注意 antd 的 affix 外壳会被内部 input 撑高，需要同时压外壳高度和 `padding-block`。
- `useListPage()` 提供分页、表格函数 ref 和横滚条数据源。表格绑定 `:ref="setTableRef"`，页脚绑定 `:source="stickySource"`。
- 使用页脚横滚条的列表，根容器添加 `page-list`（例如 `<Page class="page-list">`），复用共享样式隐藏表格原生横滚条，只保留分页上方的一条横滚条。
- 列设置和列宽持久化使用各业务独立的 key；复制页面必须更名。列结构变化（增删列、改固定宽为弹性宽）时同时给 key 升版本，否则旧浏览器里保存的宽度会把整张表按比例撑开，操作列右侧出现空白。
- 列表列从「字段注册表」派生（示例见 `views/examples/items/example-fields.ts` + `utils/detail-fields.ts` 的 `fieldsToColumns`）：详情抽屉字段与列表列共用同一份声明，新增字段只登记注册表即自动进列设置，未标 `list: true` 的默认不勾选、由用户在列设置开启。已存偏好按 key 合并，新字段追加到面板末尾，无需给存储 key 升版本。可排序字段的键必须在后端 `sortableFields` 白名单内；列设置可勾选的字段要在后端 `excelColumns` 保持同键（导出列按 `cols` 参数取白名单，键名漂移会被静默丢弃）。
- 工具栏能力显式启用：`show-create` 开启新增，`menu-items` 配置导入、导出和列设置，并同时接入处理器、URL 和权限码。默认没有业务操作。
- 删除使用二次确认；名称列可打开详情。操作列只放文字链接（编辑、删除），不使用图标，避免「图标 + 文字」重复占宽；列宽按现有按钮收紧（示例为 88px），后续新增按钮时再显式加宽，不预留空列。表格内按钮字号跟随正文 14px。
- 勾选行后显示批量操作条；翻页、改变筛选或刷新数据时清空勾选，避免误操作其他页面的记录。批量删除逐条复用单条删除，并展示成功数量与失败原因。
- 批量操作条以**覆盖**方式顶替整条工具栏（筛选区、新增与功能入口一并隐身），不要用 `v-if` / `v-show` 把工具栏从文档流里摘掉——那样工具栏高度塌陷，下方表格会向上跳。正确做法：工具栏包一层 `.toolbar-slot`（`position: relative`），多选时只给工具栏 `visibility: hidden`（保留占位、移出可访问树与 Tab 序列），批量条 `position: absolute; inset: 0` 盖满整个插槽。表格位置与高度因此完全不变。
- 批量条视觉用「色带 `--color-layer-hover` + 左侧 2px 墨条」，不加完整边框（会和表格外框形成双框）。计数在左，操作项**紧跟计数靠左**排列，不要 `margin-left: auto` 甩到右边界。
- 批量条的进出用 `<Transition name="batch-fade">` 做交叉淡入：工具栏 `opacity` 140ms 淡出（`visibility` 延迟 140ms 再生效，保留占位），批量条延迟 40ms、180ms 淡入并上移 4px 归位。只动 `opacity` / `transform`，`prefers-reduced-motion` 下由全局规则关闭。
- 批量条内部的按钮容器叫 `.batch-bar-actions`，**不要叫 `.batch-actions`**：后者已被「批量删除结果」弹窗占用，带 `margin-top: 12px`，会让按钮在条内下沉约 6px（同一文件内后定义的规则胜出）。
- 勾选列显式给宽度：`rowSelection` 里写 `columnWidth: 36`，配合 `style.css` 里 `.ant-table-selection-column { padding-inline: 0 }`，让 16px 复选框在列内居中且两侧留白均等（实测左右各 8px）。
- **必须保留至少一列没有固定宽度**（弹性列，通常是「说明」这类长文本列）。`table-layout: fixed` 下若所有列都有宽度，浏览器会把表格宽于列宽之和的部分**按比例**摊给每一列——勾选列会从 28px 被放大到 50px 以上，且看不出原因。因此 `useResizableColumns(key, columns, defaults, flexKeys)` 的第 4 个参数要传弹性列的 key（例：`['description']`），弹性列不给 resize 手柄、不落盘宽度，历史遗留的宽度也会在加载时被丢弃。
- 导出入口使用工具栏；默认导出当前筛选命中的全部记录，批量导出只取选中记录。导出列及顺序跟随当前可见列，服务端以模块白名单和同一数据范围兜底。选中上限500条、筛选导出上限50000条，超限明确提示。
- 事项标题、说明、描述、通知内容等长文本使用 `table-long-text`，保留换行并允许连续长字符串断行；可点击的长标题同时取消按钮固定高度和单行限制。编码、状态和日期等短结构化字段保留原显示方式。
- 名称列用文字按钮而不是链接按钮：主色文字加 600 字重，默认不加下划线，悬停或键盘聚焦时才出现下划线，避免整列变成一排链接。表格正文与表头统一 14px；只有说明这类长文本列不设固定宽度，用来吸收剩余空间。

## 表单和详情

- 新增使用纵向表单弹窗；普通查看与编辑共用 `DetailDrawer`，在相同字段位置切换输入控件；审批、指派等流程动作保留专用交互。
- 列表编辑等待完整详情后进入编辑态；保存成功重读服务端详情并刷新列表，保存失败保留草稿。取消丢弃草稿并重读详情；关闭或切换记录时重置编辑状态。接入示例见 `ExampleDetailDrawer.vue`。
- 保存期间显示 loading，阻止重复提交和关闭；抽屉在窄屏内完整显示，标题与操作按钮分行，输入控件填满字段容器。
- 输入规则由后端执行，前端预校验用于及时反馈。Excel 导入不能绕过相同规则，需展示成功数量和错误行。
- 详情加载时清除上一条记录；失败时显示反馈，避免展示旧记录造成误解。
- 标准业务单据采用持久 `?detail=<id>&tab=<合法页签>` 定位；关闭只清除单据参数，切页签保留草稿。参考示例页面及 `docs/standard-document-history.md`。已有管理页的 `useDetailDeepLink` 仍为一次性消费，不应直接用于标准单据的页签刷新定位。

## 视觉

- 使用现有 CSS token；主题和颜色变化修改其来源，文档不维护另一份色值表。间距、字号、行高和框架尺寸取 `style.css` 的 `--space-*`、`--text-*`、`--lh-*`、`--header-h` 等令牌，不写裸值。
- 暖白画布、近黑主色、等宽字体和 1px 细线；容器方角，按钮、输入框和标签使用 4px 圆角，无渐变和阴影。功能图标使用 Ant Design 图标组件；ASCII 方括号只用于品牌标记、章节序号和空态文案。图标操作配 tooltip 或无障碍名称。
- 正文 16px / 1.5，辅助文字 14px，页面标题 20px；Berkeley Mono 未随项目提供时使用本机等宽回退，中文回退到无衬线中文字面（苹方 / 微软雅黑）。登录和首页的主标题为 38px，窄屏 28px。
- 可点击文本（标题列、文字按钮、正文链接）用深蓝 `--color-link`（`#0056b3`，悬停 `#004085`），危险操作保持红色；主按钮仍是墨色实心，不参与链接蓝。`#007aff` 在暖白底只有 3.92:1，不用于正文链接。
- 侧栏当前项整块反白，作为「我在哪」的第一线索；面包屑显示模块层级（首页 / 系统管理 / 用户管理），折叠按钮与面包屑之间用细线分隔。
- 顶栏与侧栏使用暖白背景；深色只用于首页和登录页各自的一块终端式欢迎区。错误、警告和成功保留语义色，常规导航、选中态与主操作保持中性。
- 使用原生像素尺寸，不对 html 或浮层额外 zoom。管理列表满宽、内部滚动、单一页脚横滚条；96px 的大段间距仅用于首页说明内容，不能加入表格滚动链。
- 移动端沿用响应式页面，避免固定宽度使表单或关键按钮超出屏幕；窄屏弹层需要可操作的滚动区域。窄屏（≤768px）侧栏为覆盖式抽屉，内容区占满宽度，抽屉打开时锁定背景滚动。
- 通用弹窗和抽屉的滚动、层级与定位问题在共享组件修复，再检查所有调用页面。

## 交付检查

检查加载、空数据、接口失败和有数据四种状态；检查分页、搜索、列宽持久化、详情切换、保存失败、窄屏布局和权限入口。测试和构建通过后，交互变化仍需浏览器检查。
