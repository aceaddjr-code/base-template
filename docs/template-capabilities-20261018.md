# 模板列表、导出与编辑能力完善

日期：2026-10-18。实施范围为示例事项标准页和已有共享能力；用户、角色、菜单等系统管理页面继续保留各自专用流程。无数据库结构、生产权限配置和依赖变更。

## 已完成的四项能力

| 能力 | 当前行为 |
|---|---|
| 批量操作 | 勾选行后显示“导出选中、批量删除、取消选择”；删除二次确认，逐条调用现有单条删除，成功项保留，失败项逐条显示原因；刷新、筛选、排序或翻页时清空勾选 |
| 长文本换行 | 示例事项“标题”“说明”和站内通知“内容”完整换行，保留换行符，连续长字符串可以断行；空值显示 `-`。标题保持可点击查看详情；编码、状态、日期等结构化短字段保持原规则 |
| 导出 | 工具栏导出当前筛选命中的全部记录；选中导出取选中记录与当前筛选、数据范围的交集。列及顺序跟随列设置，后端白名单兜底；状态导出中文，时间导出为 Excel 日期 |
| 编辑 | 列表查看、列表编辑和详情内编辑共用同一抽屉；加载完整详情后编辑，在原字段位置切换控件。保存后重读详情并刷新列表，取消后丢弃草稿并重读；保存失败保留草稿 |

新增继续使用原有纵向表单弹窗。系统管理专用授权、部门编辑及其他流程弹窗不进行普通业务编辑迁移。

批量操作单次最多500条；筛选导出最多50000条，超过上限明确拒绝。空选中、非法ID、超限请求不会静默变成全量操作。导出指定列全部无效时返回错误，不自动导出其他列。默认完整导出可以重新导入，中文展示状态只在 Excel 导入入口转换，HTTP DTO 仍执行原来的内部状态验证。

## 实现入口

- 标准列表：`frontend/src/views/examples/items/index.vue`。行勾选、批量结果、当前筛选、排序、导出列均在业务页面接入。
- 详情数据生命周期：同目录 `ExampleDetailDrawer.vue`；字段与状态显示：`example-options.ts`。父页面仅持有记录ID、是否打开以及本次是否直接进入编辑。
- 通用抽屉：`frontend/src/components/DetailDrawer.vue`。提供原地编辑、保存中防重与关闭保护、取消重载入口；同一ID的详情刷新不会误判成记录切换，切换记录时旧保存结果不会刷新新记录。
- 长文本：`frontend/src/style.css` 中 `table-long-text`，用于两个真实页面；站内通知仅调整内容列。
- 导出URL与批量API：`frontend/src/api/example.ts`。
- 查询与导出：`backend/src/common/services/crud-base.service.ts` 内列表和导出共用同一查询构造；`common/utils/list-query.ts` 共用请求解析，`common/utils/excel-helper.ts` 保留日期类型。
- 示例业务：`backend/src/modules/example/example.service.ts`、`example.controller.ts`、`example.dto.ts`。批量删除保留在业务模块，没有为单个示例新建通用批量框架。
- 批量删除审计继续记录为删除动作：`backend/src/common/interceptors/audit.interceptor.ts`。

## 权限与数据范围

批量删除使用现有 `example-items:delete`，导出使用现有 `example-items:export`，编辑使用现有 `example-items:update`；前端 `v-access` 与后端权限守卫同时接入。没有新增批量专属权限码。

批量删除逐条执行已有范围和他人删除开关，范围外记录不会被删除；导出与列表共用 keyword、状态、排序、额外业务筛选和数据范围。现有 admin 例外、他人查看与编辑双开关、独立删除开关保持不变。普通修改接口不增加新的业务状态限制，也不扩大原有资格。

## 复制到新业务

1. 按现有新业务清单修改路由、权限码、scopeKey、表名、菜单和存储key。
2. 列全集保持稳定；导出列直接从可见列派生，排除序号及操作列。业务的 `excelColumns` 是后端唯一导出字段白名单，不另写前端可导出列数组。
3. 自由长文本单元格使用 `table-long-text`；不要同时保留 `ellipsis`、`truncate` 或 `line-clamp`。
4. 普通详情用同一抽屉承载查看和编辑；显式配置字段、控件类型、长度和必填规则，业务包装组件负责完整详情加载和更新后重读。
5. 批量删除复用业务的单条 `remove`；有审批或状态门控时继续执行原门控，失败项给原因。新增第二个真实使用方前不提取新批量抽象。
6. 复验按筛选和选中导出、列顺序、越权拒绝、部分失败、编辑保存/取消/失败、关闭重开和窄屏。操作权限变化后重新登录。
