# 登录页只记住用户名验收

2026-11-17 将原 PR 的「记住密码」调整为「记住用户名」。本目录 before 图片为原主分支，after 图片已更新为调整后的页面；remembered 图片只回填演示用户名，密码框为空。

- localStorage 仅保存 `{ v: 1, username: '…' }`；取消勾选立即删除。
- 首次访问清除旧 `starter-login-remember` 凭据记录，只迁移其中的用户名；不解码旧密码。
- 登录成功且勾选后保存用户名，失败不保存；密码由浏览器密码管理器决定是否保存及回填，保留 `autocomplete="username"` 和 `autocomplete="current-password"`。
- 前端测试：43 文件、265 测试通过；前端生产构建通过。
- Chrome 无头浏览器加载本分支生产构建，按 1440、390、320 三档宽度验证空态、请求加载、失败提示、成功后保存、刷新回填、取消记住及旧凭据清理，均通过，未出现页面横向溢出。桌面与移动截图已人工检查。
- 浏览器验收使用隔离上下文、演示账号和拦截的 API 响应，没有访问真实账号或数据库；不代表浏览器原生密码保存弹窗或真实后端登录已逐项验收。
