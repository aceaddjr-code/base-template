## 第二轮：界面精修

保持等宽终端风格，只调整层级、密度与状态反馈，不改动 `DESIGN.md` 的颜色与字体定义。

- 令牌层：新增间距（`--space-1..8`）、字号（`--text-display/title/heading/body/aux`）、行高、细线（`--rule`、`--rule-strong`）与框架尺寸（`--header-h`、`--sider-w`、`--row-h`、`--page-pad`）；组件里散落的 rgba 和十六进制改为令牌引用。
- 框架：侧栏选中态改为「浅底 + 2px 墨条」，折叠态只保留居中标记并修掉标题文本溢出；品牌标记为墨色方块；通知未读数写入方括号（`[!2]`）；≤768px 侧栏改为覆盖式抽屉，内容区占满宽度，抽屉打开时锁定背景滚动。
- 列表：表头统一浅底 + 1px 深色分隔线，行高 44px；选中行中性底色 + 左侧墨条；空态去掉插画改用 `[ 暂无文案 ]`；分页当前页反白；工具栏搜索框与按钮同高，窄屏搜索独占一行；批量操作条附左侧墨条。
- 页面外壳：页面标题 20px（正文 16px、辅助 14px 不变），说明限宽 68ch；窄屏隐藏「今日」日期。
- 首页：深色区增加标题栏（工作台 / 日期），统计改为三列带竖线；章节标题自动编号 `[01]`；入口与步骤增加悬停反馈。
- 登录页：左侧整块深色，修正 38px 标题在窄栏折行，补三条权限说明。
- 详情与表单：字段标签列收窄并铺浅底，分组标题用 1px 细线，抽屉头与页签间距统一；表单错误文案和必填标记统一语义色。

## 第三轮：直观性修复（P0/P1/P2）

审查结论：符号要解码、位置靠推理、首页是说明书、中文落在宋体、状态没有抓手。本轮逐项处理。

- 图标：移除 `.anticon` 的 ASCII 替换，恢复 Ant Design 图标；菜单图标按后端 `icon` 字段映射（`utils/menu-icons.ts`），未知名称回退文件夹/文档。方括号只保留品牌标记、章节序号和空态文案。
- 位置感：侧栏当前项改为整块反白（`#201d1d` 底 + `#fdfcfc` 字，16.3:1）；面包屑按菜单层级补全（首页 / 系统管理 / 用户管理）；折叠按钮换成图标并用细线与面包屑分隔，避免读成「返回上一页」。
- 首页：首屏改为「问候 + 可访问模块 / 功能入口 / 未读通知 + 最近访问 + 模块入口」，模块入口不再暴露路由路径；快速开始与框架能力收进「开发者参考」折叠区。新增 `useRecentVisits`（localStorage，最多 6 条），由侧栏在路由变化时记录。
- 字体：中文不再回退 NSimSun，改为 JetBrains Mono / IBM Plex Mono + Noto Sans Mono CJK / 微软雅黑 / 苹方等无衬线中文字面；CDP 实测页内中文为 Microsoft YaHei UI，拉丁字母为 Consolas。
- 状态与操作：状态标签改为「色点 + 文字」，进行中用蓝色、待处理中性灰、已完成绿色；表格操作补编辑/删除图标；行悬停由 `layer-01` 提到 `layer-hover`。
- 登录页：去掉重复的「[ 登录 ]」标签与 `[x]` 项目符号，改为方块列表符；在线状态用绿点。

验证：`vue-tsc --noEmit` 通过；`vitest run` 12 个文件 73 项通过；`vite build` 通过；1440×960 与 390×844 截图核对，`scrollWidth === innerWidth`。截图见 `docs/design/ui-check-20261018/`。

### 后续微调

- 操作列只保留文字链接（编辑 / 删除），移除「图标 + 文字」的重复占位；示例事项操作列默认宽度 140 → 100，把宽度让给说明列。系统管理页的操作列沿用原有的纯图标按钮，保持窄列。
- 标题列去掉常驻下划线：原生文字按钮 + 600 字重，悬停或键盘聚焦才出现下划线；表格正文与表头统一 14px，说明列改为弹性列，行高 72 → 56。
- 可点击文本统一为深蓝 `#0056b3`（悬停 `#004085`）：标题列、`.ant-btn-link` 文字按钮、正文链接、首页「打开 / 清空记录」。`#007aff` 在暖白底仅 3.92:1，故取 accent-hover 档；删除等危险操作保持红色。
- 表格内按钮字号跟随正文 14px（antd 按钮默认吃 16px 的 token，在表格里偏大）；示例事项操作列宽度 100 → 88，按现有两个链接收紧，不留空列，后续加按钮再显式加宽。
- 搜索框高度：antd 的 `.ant-input-affix-wrapper` 会被内部 input 撑到 52px（36 + 7×2 padding + 2 边框），按钮只有 36px。改为外壳 36px + `padding-block: 0`，两者同高，工具栏从 68 收到 52。
- 表格左外侧补 1px 边线（首列 `border-left`），与右侧单元格边框闭合。
- 表头固定：改用 `scroll.y` + 新增的 `useTableScrollY`（ResizeObserver 实测「容器 - 工具栏 - 表头」高度）。设置后页面不再滚动，`overflow` 落在 `.ant-table-body`，表头由 antd 单独渲染；同时为 body 放出竖向细滚动条，横向仍由页脚统一横滚条承担。
