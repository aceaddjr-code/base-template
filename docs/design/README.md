# OpenCode 风格适配

`DESIGN.md` 是用户提供的设计规范原文，保留在项目中供后续开发参考。它主要描述营销网站，本模板将其视觉语言应用到企业管理系统。

## 样式入口

- `frontend/src/style.css`：色板、字体栈、控件与浮层覆盖。
- `frontend/src/App.vue`：Ant Design Vue 的主题 token。
- `frontend/src/layouts/BasicLayout.vue`：浅色导航、56px 顶栏、窄屏侧栏。
- `Page`、`PageToolbar`、`ListFooter`、`DetailDrawer`：共享页面、操作、页脚及详情外观。
- 首页和登录页：各自只有一块深色终端欢迎区，其余为暖白画布。

## 企业界面适配

- 保留本项目名称和中文业务文案，不复制 OpenCode 产品名或营销内容。
- Berkeley Mono 是商业字体，参考资料没有附字体文件。优先使用用户本机已安装的 Berkeley Mono，其次 JetBrains Mono、IBM Plex Mono、系统等宽字体；中文没有可用的等宽正文字体，回退到苹方 / 微软雅黑等无衬线中文字面，避免 14px 宋体发飘。不加入远程字体依赖。
- 正文 16px，辅助信息 14px；管理列表保持满宽，分页与唯一横滚条仍位于页脚。营销页的 960px 内容列和 96px 大段间隔不用于表格，首页介绍段落采用该间距。
- 常规入口使用近黑主色，可点击文本（标题、文字按钮、正文链接）用深蓝 `#0056b3`，悬停加深到 `#004085`；`#007aff` 对比度不足，不用于正文链接。错误、删除、警告和成功仍使用相应语义颜色。危险按钮和失败提示不能被中性主色覆盖。
- 控件 4px 圆角、容器方角、1px 细线，无装饰阴影或渐变。浮层使用边框及遮罩与背景区分。
- 功能图标使用 Ant Design 图标组件，形状承担语义；ASCII 方括号只保留给品牌标记、章节序号和空态文案，避免同一符号被读成多种含义。图标按钮仍需可理解的无障碍名称或 tooltip。
- 移除 html 的 0.85 缩放及浮层反缩放，同时使用原生视口高度，防止控件尺寸和拖动坐标不一致。
