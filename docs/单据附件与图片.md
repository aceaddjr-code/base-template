# 单据附件与图片

示例事项详情新增「附件/图片」页签。附件区提供文档、压缩包、文本文件列表；图片区提供 PNG、JPG、JPEG、WebP、GIF 缩略图和大图预览。两个区域分别上传，按文件扩展名归类，单文件最大 500MB。上传后自动保存到当前单据，挂接失败保留临时文件 ID，可重试保存。

查看、下载和图片预览要求 `example-items:view`；上传、删除要求 `example-items:update`。后端同时校验单据数据范围和他人查看/编辑开关。绑定只接受当前上传者的临时文件；同一文件挂接到同一单据可安全重试。普通用户不能通过通用附件端点绕过单据授权；系统管理员保留附件管理下载能力，业务附件删除统一从单据执行。

附件通过 `ChildSpec` 声明为事项子表，使用 `entityId` 和 `entityType=example-items`。来源类型参与子表读取、写入和删除，防止相同 ID 的不同业务相互影响。单据删除时附件同事务软删；文件由现有定时清理任务回收。临时清理和挂接使用附件行锁，清理前重新确认状态。上传、删除附件写入操作日志，不修改单据字段版本。

复用既有 `attachments` 表和私有存储目录，无新增数据库结构，无需执行 SQL。发布需更新前后端并重启后端；回滚到旧版前应先处理新增的单据附件，因为旧版没有对应的业务授权入口。已有单据字段、履历和本次之前的本地修改保留。

验证包括后端全量 Jest、前后端构建、前端分区/失败重试测试，以及隔离 MySQL 的真实 HTTP 上传、图片内容回读、越权拒绝、重复挂接、来源隔离和删除级联测试。隔离测试使用独立数据库，测试日志中的注入失败用于验证事务回滚。

客户端上传请求超时单独设为 30 分钟，其他客户端接口保持原有超时；Node 服务接收完整请求的 requestTimeout 同步设为 30 分钟。应用端通过磁盘流接收，不把整个大文件读入内存。部署使用反向代理时，需允许至少 500MB 文件加 multipart 开销，并配置相应的请求接收超时；本仓库未提供代理配置，因此本次未修改外部代理。

修复后的交互：同一单据切换页签保留附件面板和待保存状态；上传、保存或删除期间阻止关闭及切换记录。挂接失败时可重试；关闭或离开当前记录会确认是否放弃待保存状态，未挂接文件仍按临时文件保留期回收。浏览器离开提示沿用共享机制，强制卸载会取消上传请求。

文件名在 multipart 入口恢复浏览器的 UTF-8 编码；存储路径从 Multer 实际落盘路径计算，不在上传结束时重新计算月份。文件记录保存失败时回收已落盘文件；清理失败会返回明确错误。已存储的历史乱码名称不在本次自动修改范围内。

支持格式已扩展：文档含 Office 模板、OpenDocument、RTF、结构化文本；压缩包增加 TAR、GZ、BZ2、XZ；附件增加 DWG/DXF/STEP/IGES/STL 等工程图和模型、PSD/AI/EPS 设计文件及常见音视频。图片区增加 BMP、AVIF、ICO、TIFF、HEIC/HEIF、SVG。TIFF、HEIC/HEIF 和 SVG 提供原图下载，不通过本系统的内嵌预览加载；SVG 即使显式请求 preview 也以附件响应。两个分区不再常驻显示格式和大小说明，文件上限仍为 500MB。
