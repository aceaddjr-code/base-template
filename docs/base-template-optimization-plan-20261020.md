## 1. 模板定位与范围

目标是一个可复制的企业后台底座：账号与授权、系统管理、列表表单交互、数据交换、文件、任务和维护能力由模板提供；后续项目新增业务表、接口、页面、权限码和菜单，即可开发自己的业务模块。

通用能力不内置采购、合同、库存等业务字段、状态或审批资格。基础功能可以按项目需要启用入口；入口显隐不代替后端授权，也不为未使用能力预先堆叠基础设施。

实施约束：

- 保留 Vue 3 + Ant Design Vue、NestJS + TypeORM + MySQL；参考外部项目的能力边界，不整体迁移框架或表格库。
- 保留 `docs/design/DESIGN.md` 的现有主题适配、中文文案和 `docs/页面布局规范.md`。新列表使用 Page、PageToolbar、ListFooter、useResizableColumns。
- 保留用户已确定的密码最短 **3 位**规则；本方案不改变现有账号密码。
- 操作权限、数据范围、业务状态分别裁决。前端 v-access 管入口，后端权限码和数据范围兜底；不按角色中文名、职位或人员姓名写死资格。
- common 只放跨业务稳定能力，具体规则留在业务模块；有两个真实调用方后再提取新共享接口。
- 新增使用纵向表单弹窗；普通查看和编辑共用 DetailDrawer，原位切换、保存/取消后回查看态；审批和指派等流程保留专用交互。

## 4. 筛选、列表与个人偏好详细方案

### 4.1 筛选布局和控件（F01/F04/F27）

- 默认紧凑一行：关键词、状态多选、更新时间、查询、重置、展开更多。创建时间等低频字段放展开区；用户/部门/金额等仅在业务真实存在时提供。
- 支持文本、字典多选、日期范围、数值区间和按需远程人员/部门选择。后端模块明确登记允许字段和操作符，不接收任意列名、SQL 或任意表达式。
- 日期快捷项至少有今天、近 7 天、本月；按明确的业务时区和结束日规则转换。保存“本月”时保存语义，每次应用重新计算，不固定成某月日期。
- 已选标签只展示已应用条件，例如“状态：待处理、进行中 ×”；显示后端匹配总数。可逐项移除、清空；收起筛选区不清空条件。
- 输入是草稿，查询/Enter 才应用；重置恢复模块基准条件并查询第一页，不暗中重新套回个人默认视图。删除标签/应用视图属于明确查询动作，替换未提交草稿前给予提示。
- 同字段多选为 OR，不同字段为 AND；关键词在登记的搜索字段内做 OR，再与其他条件 AND。任意分组、跨关联表和嵌套“且/或”后续按真实需要扩展并限制复杂度。
- 状态主入口统一到常用条件区，表头继续排序；若保留表头筛选，必须受控同步同一状态。导出读取已应用快照，不能把尚未提交的输入用于导出。
- 改条件回第一页并清空勾选；普通刷新保留页码，复用现有迟到请求保护。展开区变化后重测表格高度，仍只保留页脚横滚条。

### 4.2 当前正确性与缓存（F02/F03/F26）

以下两段是实施前源码基线，F02/F03 已于 2026-10-21 修复并完成隔离运行验证；保留基线用于解释改动缘由，不再表示当前代码仍存在这些问题。

通知页当前在后端分页后过滤 data.list，再把过滤后当前页长度作为未读 total；列表接口未接收该条件。需要下推过滤并使用同一数据库条件计数。该判断来自源码，本轮未做运行时复现。

字典 refresh 当前优先命中模块 Map 缓存。增加明确的强制刷新/编码失效和同请求合并；管理页保存成功后同步失效。偏好按账号和模块区分，新旧 key 迁移需保留已有列设置，不能一刀清除用户配置。

个人常用视图先保存条件和排序；列宽/显隐继续由列偏好管理，不在应用视图时暗中覆盖。第一版选本机保存或后端同步之一并明确告知范围；不先做团队共享。URL 不写令牌、敏感人员信息或授权结果。

### 4.3 列表、详情与返回连续性（补充 F04/F20/F35）

从列表打开详情并返回时，保留已应用条件、页码、排序和合理滚动位置；记录删除或不再匹配时落到相邻记录/列表操作区。现有 useDetailDeepLink 已消费 ?detail 并清理参数，不应误报为没有详情直达；若增加关闭后返回或可复制链接，先明确浏览器前进/后退和抽屉历史语义，避免历史栈循环。

快捷键遵守输入控件语义，不拦截中文输入法候选确认、不把 textarea 的 Enter 当保存。筛选查询与保存快捷操作分别定义，菜单搜索沿用自己的 Ctrl/Cmd+K。页面离开仍执行既定草稿保护。

### 4.4 组织树与基础档案（F39/F40）

组织树增加名称/编码搜索、命中高亮、自动展开祖先和清空恢复。节点选中、手动展开、搜索展开分别管理；当前选择未在搜索结果中出现时仍明确显示生效条件，不能静默切回全部。部门是否包含子部门、人数统计与列表必须同口径，并遵守原组织信息可见规则。

以下为首轮实施前源码基线，`findAll(keyword)` 的祖先路径问题与用户页树搜索已于 2026-10-22 由 F39 实施修复（见[实施记录](optimization-implementation-20261021.md)第 6 节）；保留基线用于解释改动缘由。原 `DepartmentService.findAll(keyword)` 先按关键词裁剪记录，再从 parentId=null 构树；子节点独立命中且祖先未命中时会消失。原用户页从启用部门全量列表构树、无搜索框。现口径为命中节点 + 祖先链，命中节点未命中的子树裁剪；搜索结果保留可展示祖先路径；若未来切换懒加载，不能只在已加载节点里冒充全树搜索。

当前部门已有子部门/用户引用删除检查，角色已有主角色/附加角色引用检查，字典类型删除前检查选项；这些规则保留。补充的是字典存储值变更/删除的业务引用规则和历史展示：启用选项用于新增选择，已停用的旧值仍能回显名称和“已停用”，不能编辑无关字段时悄悄清空。已使用的值原则上稳定；变更需要模块明确的影响分析和迁移方案，不遍历未知业务表猜测引用。

字典当前 findByCode 仅返回启用项，useDict.labelOf 缺项回退原值，已有容错应保留；按需补历史解析。显示当前名称还是保留业务发生时名称由模块决定，不能把全系统快照机制默认加到每条记录。历史解析同样受字段和数据权限控制。

后端保存同时区分保留旧值和主动改选：原记录已保存的停用值未改变时允许保留，新增或改选时不能使用停用值。必须通过当前记录回读判断是否未改，不能信任前端提交的“原值”；具体业务若另有状态限制，由模块明确反馈。

## 5. 数据写入、文件、导入导出与任务

### 5.1 写入完整性（F05/F06/F07）

已有创建/更新事务继续保留；通用主子表删除应整体包事务，并通过子表失败验证回滚。当前示例未配置子表，不能把待完善点描述成已发生数据丢失。

多人编辑采用服务端原子版本条件更新，后提交者收到冲突提示并保留草稿，可重新加载对照。幂等只用于需要防重复的真实动作，覆盖重复请求、失败重试与业务唯一约束；按钮 loading 和唯一任务 ID 均不能代替业务幂等。

### 5.2 附件生命周期（F08）

现有上传过滤、容量限制和随机文件名保留；新增文件元信息与业务关联，返回 fileId。临时上传、绑定、解绑和过期清理可追踪；取消新增不留下永久无归属文件。

公开头像与私有附件分别处理。私有下载、预览、删除先校验关联记录的操作权限/数据范围；不能仅凭静态 URL 绕过记录授权。存储删除失败可重试，不误删仍有引用的文件。先支持本地磁盘，有真实第二种存储需求时再提取适配层。

### 5.3 导入向导与结果（F30）

流程：下载当前模块模板 → 选文件 → 服务端预检 → 查看错误/统计 → 确认导入 → 完整结果。现有后端已经收集带行号的 errors，页面目前只在提示里显示前几项；保留后端校验与完整错误，补明细面板和可下载的错误文件，不能误称原来没有行校验。

独立预检是新增能力，不写业务数据；确认时仍重新验证授权、字典、引用及当前数据，不能信任陈旧预检结果。模块明确部分成功或整体回滚语义；新增/覆盖/跳过重复按模块业务定义。模板列、字典值、Excel 解析与 DTO 验证保持一致，导入文件和错误结果受权限及保留时间控制。

### 5.4 导出、打印与后台任务（F09/F21）

保留当前筛选/选中导出、列顺序和服务端白名单。数据大时受理为任务并返回任务编号，提供排队/运行/成功/失败、进度和结果下载；小数据同步导出继续使用。

任务受理、执行和结果下载按需要重新检查当前授权，不能存整份 JWT 作为长期资格。用户只看允许的任务，失败原因脱敏，重试幂等，结果过期同时清理文件。先验证真实耗时备份/大导出，再决定数据库任务表或 Redis/worker；不默认引入额外服务。

打印使用独立干净视图，支持 A4、长文本、分页和浏览器保存 PDF。明确当前页/选中/全部的范围，不把页面 DOM 当成已加载全部数据；服务端 PDF、套打及打印模板设计器不属于首版。

### 5.5 批量操作的范围、结果与恢复（F37）

已有勾选、删除确认和逐条失败原因保留；明确显示“已选 N 条（当前页）”，全选的语义与实际数据一致。首版继续翻页/改条件清空选择，不因组件库支持 preserveSelectedRowKeys 就自动启用跨页或全量操作。

结果面板区分成功、明确失败和结果待确认；支持查看失败原因、复制/下载允许的失败明细，并只重试仍有权限且明确失败的原始 ID。成功项不再次提交，失败重试重新执行当前业务状态规则。已收到逐条明确失败结果的同步批次可直接按上述规则重试，无需强绑任务中心。请求超时不等于后端失败；结果未知或需要跨页面可靠恢复的批次，先有操作编号与状态查询，再开放恢复/重试入口，不能把未知项直接判成失败。

长批次的进度来自服务端实际完成数，不能显示编造百分比。未实现后端协作取消时，不提供暗示事务回滚的“取消执行”；未来取消只能阻止尚未开始的记录，已完成结果仍可查询。异步任务、幂等与操作日志按 F09/F07/F11 接入，不单独再造一套后台任务。

## 6. 系统管理与用户体验

- **自助改密（F16）**：独立受认证接口，从当前身份取得用户 ID；后端验证旧密码并保存 bcrypt，新密码确认，递增会话版本后重新登录。管理员重置与本人改密分别处理，密码不进日志/草稿，最短 3 位保持不变。
- **菜单搜索（F17）**：Ctrl/Cmd+K、中文别名、方向键/Enter/Esc；只搜索已授权菜单。历史按账号隔离，权限变更后过滤失效项；不是跨业务全文搜索。
- **系统参数（F18）**：维护预登记的运营配置，类型、取值、前端可见性、修改权限、审计和立即/重启生效规则明确。数据库密码、JWT 密钥仍属于部署配置，不通过参数页面下发。
- **公告（F19）**：独立维护草稿/发布/撤回和历史阅读；先首页列表及详情，富文本采用受控渲染。定向受众、有效期、回执按后续需求设计；WebSocket 在线推送不等于可靠离线送达。
- **表单草稿（F20）**：优先关闭/离开未保存提醒，再加真实长表单的明确保存/恢复。按账号/表单/记录隔离，敏感字段不写浏览器草稿；提交后清理，恢复前复核权限和记录版本。
- **帮助（F22）**：固定入口、按页面关联说明、FAQ、更新记录，与界面实际入口对应。首版 Markdown 即可，不建立额外内容平台。
- **页面水印（F23）**：按项目需要启用，姓名/时间不过度遮挡表格；不能宣称防止截图或替代脱敏。文件水印另行设计。
- **设备会话（F24）**：已有 tokenVersion 能使旧授权失效，新增的是设备级可查询/可撤销记录。是否需要刷新令牌单独评估，不重签旧授权快照。
- **通知（F25）**：先让一条真实业务提醒完成产生、读取、已读和有权限的记录直达，再按需要补去重/重试；通知不存在或记录无权访问时有明确反馈。
- **回收站（F28）**：仅开放适用模块，恢复需处理当前授权、唯一键、关联记录和业务状态；硬删除清理与恢复权限分别定义。
- **异常与网络反馈（F31）**：保留现有 404 和 401 跳登录；给无权限、接口失败、无匹配、断网和超时合适文案/操作。现有 GET/HEAD 已有一次网络重试，不能再叠加无限重试；写操作不自动重放。浏览器 online 事件只说明网络状态，不证明 API 可用。
- **版本更新（F32）**：检测构建版本并提示用户刷新；检查未保存内容，避免强制刷新丢输入。版本文件/接口明确缓存策略，资源加载失败避免无限刷新和重复提示；开发环境可关闭。

### 6.1 表单错误与校验反馈（F34）

示例新增/详情编辑和用户新增已接入字段旁反馈、可点击错误摘要、显式首错焦点和未保存提醒；保存失败保留输入。实施前 DetailDrawer 主要使用顶部 message.warning，现已收口这三个入口，其他管理表单继续分批接入。Ant Form 的 scrollToField 只代表滚动，不能当作已完成焦点处理。

后端已保留原 code/message/data/requestId，并追加 `fieldErrors[{path,code,message}]`；前端只按声明路径映射，未知路径放入摘要，不从中文消息猜字段。表单主动接管反馈时避免叠加全局错误提示。验证来源仍是服务端，密码最短 3 位等已确定规则保持一致；新增用户邮箱格式和密码 UTF-8 最多 72 字节也在后端验证。

字段反馈由页面承接后，全局层不再弹同一错误；没有被承接的错误有兜底，不能用“禁用全局提示”静默吞错。异步唯一性检查只接受当前输入的结果；用户修正后清除过期错误，保存失败始终保留内容。

### 6.2 键盘、焦点及触摸（F35）

现有 a-drawer、输入 aria-label、focus-visible 和 prefers-reduced-motion 保留，先在真实浏览器检查组件库已有行为，再补业务缺口。模态内 Tab/Shift+Tab 合理循环；打开时有合适初始焦点，长详情可先聚焦标题，进入编辑到首个可编辑字段。保存/取消回查看态时聚焦仍存在的编辑入口，关闭回原触发点；触发记录已删除则回到相邻行或列表操作区。

Escape 只作用于顶层弹层，未保存修改按草稿规则处理；保存中的关闭限制有可感知状态，失败或超时恢复操作。权限变化导致编辑入口消失时，焦点回到可用的详情标题或关闭按钮。

列配置当前支持拖拽，补“上移/下移”等键盘/触摸等价入口；列宽保留竖线拖动并可提供宽度输入/增减，不要求用户精确拖动细线。悬停入口检查是否有点击/键盘替代方式，图标有名称，状态文字与颜色同时表达。通过键盘、缩放、窄屏和辅助技术实测后才记录符合性结论。

### 6.3 反馈责任与可恢复状态（补充 F31）

一次用户动作只给一组有意义反馈：字段/表单错误由当前表单显示，系统错误保留可复制请求号，主动取消的查询不弹错误。刷新中可保留已确认的旧数据并标明正在刷新；请求失败时不能把旧列表伪装成新条件结果。加载和成功状态要可感知，避免连续刷新产生通知堆积。

不可操作入口区分无权限和业务条件不满足：无权入口遵循现有 v-access，业务条件不满足可在用户有权获知原因时解释，例如“先选择记录”；后端仍作最终裁决。不要为了说明按钮禁用而泄露无权访问的对象或其他用户信息。

## 7. 可维护性与新项目交付

### 7.1 排障与运行维护（F10/F11/F12/F15）

先将备份的 execFileSync 改为异步进程并提供状态/超时处理，使普通列表与健康检查可继续响应。后续恢复演练包含数据库和实际附件文件，记录恢复耗时、失败点和验证结果；存在备份文件不等于已验证可恢复。Windows 与 Linux 的备份执行器和依赖分别说明。

X-Request-ID 已有基础，应贯通错误响应、前端提示、异常、业务审计；必要变更摘要由真实写入口产生。递归脱敏、日志大小/批量限制、保留时间及审计失败可观察，避免日志系统自身循环报错。

启动前集中校验必填配置及组合关系，不把配置验证等同系统参数管理。存活检查与就绪检查分开，数据库/已启用依赖失败时不能仍标为可接流量。公开健康接口仅给必要状态，管理端诊断详情脱敏且有权限。

### 7.2 迁移、契约与自动验收（F13/F14/F29）

生产禁止依赖 synchronize。新增结构提供 docs/sql 增量补丁、版本和执行状态、顺序、备份与回滚/补偿说明；空库初始化与旧库升级分别验收，不在重启时重置已配置的菜单/授权。

OpenAPI 明确分页、统一响应包装、错误结构、导入/导出和认证方式；当前使用 Cookie，文档不能误写为只有 Bearer token。描述文件与 DTO/真实响应保持一致，按需生成前端类型并做契约检查；生成类型不能替代服务端运行时验证或权限校验。文档入口仅在受控开发/测试环境或受保护的管理环境开放。

将稳定脚本从 .scratch 整理为可交付测试，CI 跑构建、单测、控制器及隔离 MySQL/迁移验收。数据范围检查覆盖列表、详情、更新、删除、候选项、导出；检验拒绝后数据库未改变。构建/替身测试不能替代真实库回读和浏览器流程。

### 7.3 业务模块接入与模板纯净（F33）

先完善 README 与可运行示例，再按重复劳动决定是否开发生成命令。生成器只生成显式命名的业务骨架，不自动部署、自动改生产数据库或猜审批规则。

新业务固定检查：表名、路由、权限码、scopeKey、菜单、页面存储 key、Excel 列、DTO 和测试名；检查后端模块接线、前端路由、范围注册及种子/旧库 SQL。生成前列出文件，遇到已存在文件拒绝覆盖，支持预览输出。至少用两个真实模块验证后再形成公共脚手架。

模板交付不混入历史业务模块、旧账号/真实附件、环境密钥、临时库、失效文档或旧 Agent 上下文。示例可清晰移除；复制交付按路径/长度/哈希校验，而不只看复制命令返回码。

日期、时区、数值精度/单位、空值等展示规则沿用公共格式化能力并文档化；针对真实模块补缺口，不建立无调用方的字段平台。DTO、数据库、界面和 Excel 的语义保持一致。

### 7.4 请求生命周期与性能（F36/F38）

当前 Axios 已有 10 秒超时、GET/HEAD 网络失败一次重试；示例列表已有 listVersion 防止旧成功响应覆盖。扩展为查询切换/页面离开时取消无用读取，并排除 axios.isCancel/ERR_CANCELED，取消不重试、不上报普通错误；保留版本号兜底，因为取消不保证服务端停止执行，也不保证所有旧回调停止。

只对明确可安全重试的读取定义有限次数和退避；认证/权限/业务校验失败不盲目重试，写请求不默认重放。共享读取合并按账号/会话、URL 和规范化参数隔离；一个使用方取消不能中断其他仍需结果的使用方，避免引入全局永久缓存。查询节流/防抖不应延迟用户明确点击查询，也需处理中文输入法输入阶段。

性能先测量再选择实现：记录数据规模、每页条数、设备/网络、请求耗时、首屏渲染、筛选响应、展开弹层和滚动表现；使用后端慢 SQL 与查询计划定位，再决定索引、字段裁剪、分页和远程选项加载。索引是否存在以实际数据库为准，不从实体类推断。指标目标在基线后确定，不宣称未测得的加速倍数。

已有路由懒加载、服务端分页、ResizeObserver 高度重测和卸载清理继续保留。当前长文本换行导致行高可变，虚拟滚动只在实测有必要的页面验证后启用，同时检查固定列、列宽、抽屉跳转、打印和单页脚横滚；不为每页十几条记录引入复杂虚拟表格。后台定时读取遵循可见性和实际需要，事件驱动替代轮询须有可靠事件来源。
